UniSimVLA

Unified Simulation Data Engine → Multi-task Embodied Perception VLA → Closed-loop Deployment for Robots, Vehicles and Drones

Sunny Rao

Code Videos

Overview

A full-stack framework built on simulation: a unified simulation data engine produces labeled demonstrations, a multi-task embodied perception VLA learns 3D perception and navigation jointly, and closed-loop deployment tests the model back in simulation.

  1. 1

    Unified Simulation Data Engine

    One Isaac Sim pipeline for navigation and manipulation: real-to-sim scenes and assets, domain randomization.

  2. 2

    Multi-task Embodied VLA

    FutureNav-based, Qwen3.5-0.8B backbone, 3D perception heads, tracking and instruction navigation.

  3. 3

    Closed-loop Deployment

    In-simulation closed-loop tests and automated evaluation, ~500 ms per step on an RTX 5080.
